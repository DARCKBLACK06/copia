Manual de Registro de Usuario

Descripción General

Este panel permite al administrador gestionar usuarios, departamentos, sensores, pagos y visualizar reportes de estado de cerraduras y notificaciones relevantes.

Estructura de la Página

  • Menú lateral: Navegación entre vistas (Inicio, Gráficas, Documentación).
  • Panel principal: Vista general de usuario y accesos rápidos.
  • Notificaciones: Pagos próximos o alertas.
  • Departamentos: Registro de departamentos, usuarios o sensores.
  • Reportes: (Pendiente) estadísticas y análisis automatizado.

Funcionalidades

Función Descripción Archivo Relacionado
Registrar Usuario Abre un modal para registrar nuevo usuario. registro.js
Detalles Muestra información avanzada del usuario, gráficas, estado de cerradura, etc. modalDetalles.js
Modo Manual/Automático Permite cambiar el control de la cerradura desde el panel. modoControl.js
Validación de Pagos Consulta en Firestore y muestra estado actual del usuario. estadoPago.js

Tecnologías Usadas

  • HTML5 para estructura semántica.
  • JavaScript puro + Firebase SDK.
  • CSS sin Bootstrap para visual.
  • Firestore & Realtime Database como backend.
  • Toastify para notificaciones.

Recomendaciones

  • Usar IDs dinámicos correctamente.
  • Evitar rutas hardcodeadas.
  • Verificar triggers en Apps Script.
